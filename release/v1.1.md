# 深度视频桌面版 v1.1

推荐下载 **DepthVideo-Desktop-v1.1-Windows-x64.zip**（内含 Small 模型）。完整解压后双击 `DepthVideo.exe`，选择视频并开始处理。

## 本次更新

- 修复微信等深层文件夹路径导致 PyTorch 安装失败的问题。
- 运行环境固定在 `%LOCALAPPDATA%\DV\r1`，无需修改系统设置。
- 改进安装失败提示，补齐快速上手文档和文件校验。

## 下载说明

| 文件 | 用途 |
| --- | --- |
| Windows-x64.zip | 推荐的 Windows 64 位便携包，包含模型 |
| lite.zip | 不含模型的轻量包，首次额外下载模型 |
| .sha256 | 对应压缩包的 SHA256 校验值 |

**两个版本首次都需要联网准备 Python / CPU 推理依赖。不是完整离线包。** 环境准备好后可离线处理，无需 Codex、API Key 或手动配置 Python。视频留在本机。

系统：Windows 10/11 x64，WebView2 运行时，建议 8 GB 以上内存、3 GB 可用磁盘。应用尚未代码签名。

GitHub 自动附带的 Source code 是源码，不是可双击运行的发行包。

当前仍使用 CPU；约 15 秒视频在已测试电脑上处理约 56–79 秒，仅供参考。完整限制与第三方许可请见仓库 README。
